# 阶段1：需求评审与数据库设计

> 版本：v1.0（已确认）
> 日期：2026-10-06

## 一、需求评审摘要

**一期定位**：单人管理员版摄影约拍小程序，前端只读+云函数统一写入鉴权，预留二期多摄影师入驻字段（`photographer_id`）。

**核心链路**：
- 浏览 → 选套餐/器材 → 填预约表单（存草稿）→ 选填问卷 → 云函数校验档期 → 沙箱支付 → 生成档期 → 订单管理
- 三种订单：`photo_only` / `equipment_only` / `combo`
- 档期分两类：`photo`（拍摄）/ `equipment`（器材租赁），组合订单会生成两条档期
- 管理员专属：档期日历、套餐/作品/器材/美姿/订单管理

**关键约束**：
- 权限校验全部写在云函数，防止前端越权
- 图片/视频全部存在云存储
- 档期冲突校验写在云函数，不能只前端判断
- 表单自动保存草稿（一期用 `wx.setStorageSync` 本地缓存）
- 一期单人管理员，预留二期字段
- 4套主题，默认方案①清透米白柔光纪实风
- 软删除+状态位便于恢复
- 摄影师封锁（block）与器材锁定（equip_lock）独立控制：block 管控拍摄预约，equip_lock 管控器材租赁，支持组合使用
- block/equip_lock 仅管理员手动创建，不绑定订单；已有有效订单的日期禁止新增封锁/锁定

**确认的设计决策**：
1. 作品 `portfolio_id` 允许为空，可独立作为套餐样片
2. 器材保留 `stock` 字段，一期默认 stock=1，支持 stock>1
3. 预约草稿一期仅本地缓存，不建云端 draft_orders 集合
4. 拍摄档期按天锁定，时间段（start_time/end_time）选填；同摄影师同一天仅1条拍摄档期
5. 器材租赁按起止日期区间校验
6. 订单状态流转：`pending_payment → paid → in_progress → completed` / `cancelled` / `refunded`

## 二、数据库设计（10个集合）

> 约定：金额单位为**分**（Number），时间为 **Date**，软删除统一用 `is_deleted`，二期扩展字段标注【二期】。

### 7. `schedules` 档期集合

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | String | 主键 |
| `schedule_type` | String | `photo` 拍摄 / `equipment` 器材租赁 / `block` 摄影师封锁 / `equip_lock` 器材锁定 |
| `date` | Date | 日期 |
| `start_time` / `end_time` | String | 时间段 `HH:mm`（可选，按天时不填） |
| `order_id` | String | 关联订单ID（手动档期/封锁/锁定为空） |
| `equipment_id` | String | 关联器材ID（仅 equipment 档期） |
| `customer_name` | String | 客户姓名 |
| `location` | String | 地点 |
| `remark` | String | 简短备注 |
| `block_reason` | String | 【仅 block】封锁事由 |
| `block_scope` | String | 【仅 block】`photo_only` 仅拍摄不可约 / `all` 拍摄+器材全部不可约 |
| `lock_equip_ids` | Array<String> | 【仅 equip_lock】锁定器材ID数组 |
| `lock_reason` | String | 【仅 equip_lock】锁定备注（外出携带、维修等） |
| `is_manual` | Boolean | 是否管理员手动新增 |
| `photographer_id` | String | 【二期】摄影师ID |
| `status` | Number | 1有效 0已释放 2待支付锁定 |
| `is_deleted` / 时间 | - | 公共字段 |

> 档期校验执行顺序（云函数内）：① block 摄影师封锁前置校验 → ② equip_lock 器材锁定校验 → ③ 原有拍摄/器材档期冲突校验。
> - `block`：`scope=photo_only` 仅拦截拍摄类订单，器材租赁不受影响；`scope=all` 拦截全部订单
> - `equip_lock`：仅拦截独立器材租赁（equipment_only），拍摄订单自带器材不受限
> - 冲突校验：同 `photographer_id`、同 `date` 做 `photo` 互斥；同 `equipment_id`、日期区间重叠做 `equipment` 互斥
