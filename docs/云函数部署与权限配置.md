# 云函数部署 & 权限配置文档

> 版本：v1.0
> 日期：2026-10-06

## 一、云函数清单

| 云函数 | 职责 | 权限 | 是否含定时触发器 |
|--------|------|------|------------------|
| `user` | 登录、用户信息 | 登录态 | 否 |
| `content` | 公开内容查询 | 公开 | 否 |
| `manage` | 管理员内容增删改 | 仅管理员 | 否 |
| `booking` | 档期校验、建单、软锁 | 需登录 | 否 |
| `order` | 订单查询、取消、状态流转 | 本人/管理员 | 否 |
| `schedule` | 档期查询、手动新增 | 仅管理员 | 否 |
| `pay` | 沙箱支付、生成档期 | 需登录 | 否 |
| `timer` | 清理超时订单、释放锁 | 系统 | 是（每5分钟） |
| `initDb` | 数据库初始化（仅一次） | 手动调用 | 否 |

## 二、部署步骤

### 步骤1：开通云开发环境
1. 微信开发者工具打开项目，点击「云开发」开通环境
2. 记录**环境ID**
3. 打开 `app.js`，将 `cloudEnv: 'your-cloud-env-id'` 替换为实际环境ID

### 步骤2：创建数据库集合
在云开发控制台 → 数据库，创建以下集合（权限见第三节）：

```
users, packages, works, portfolios, equipment,
orders, schedules, questionnaires, pose_materials, theme_config
```

### 步骤3：初始化主题数据
**方式A（推荐）：调用 initDb 云函数**
1. 部署 `initDb` 云函数
2. 在云函数控制台测试 `initDb`，传入 `{ "action": "initThemes" }`
3. 确认 theme_config 集合有4条记录

**方式B：手动导入 JSON**
1. 在数据库控制台 `theme_config` 集合点击「导入」
2. 选择 `cloudfunctions/initDb/theme_config.json`
3. 导入模式选「插入」

### 步骤4：部署全部云函数
在微信开发者工具中，对 `cloudfunctions` 下每个云函数目录：
- 右键 →「上传并部署：云端安装依赖」
- 部署顺序建议：`user` → `content` → `manage` → `booking` → `order` → `schedule` → `pay` → `timer` → `initDb`

> 注意：每个云函数目录下已包含 `utils.js`（从 common 复制），确保自包含可部署。

### 步骤5：设置管理员
1. 在小程序端用你的微信号登录一次（会在 users 集合生成记录）
2. 在云开发控制台数据库 `users` 集合找到你的记录，复制 `openid`
3. 测试 `initDb` 云函数，传入：
```json
{ "action": "setFirstAdmin", "openid": "你的openid" }
```
4. 返回成功后，你的账号即拥有管理员权限，「我的」页会出现「管理员后台」入口

### 步骤6：验证定时触发器
- `timer` 云函数的 `config.json` 已配置 cron `0 */5 * * * * *`（每5分钟执行）
- 部署后在云函数控制台 → `timer` → 触发器，确认触发器已启用
- 可在「日志」中查看执行记录

## 三、数据库权限配置

在云开发控制台 → 数据库 → 各集合 → 权限设置，按以下配置：

| 集合 | 权限设置 | 说明 |
|------|----------|------|
| `users` | 仅创建者可读写 | 用户信息敏感，云函数内鉴权 |
| `packages` | 所有用户可读，仅管理员可写 | 套餐公开浏览 |
| `works` | 所有用户可读，仅管理员可写 | 作品公开浏览 |
| `portfolios` | 所有用户可读，仅管理员可写 | 作品集公开浏览 |
| `equipment` | 所有用户可读，仅管理员可写 | 器材公开浏览 |
| `orders` | 仅创建者可读写 | 订单隐私，管理员通过云函数查 |
| `schedules` | 仅管理员可读写 | 档期不公开 |
| `questionnaires` | 仅创建者可读写 | 问卷隐私 |
| `pose_materials` | 所有用户可读，仅管理员可写 | 美姿公开浏览 |
| `theme_config` | 所有用户可读，仅管理员可写 | 主题配置公开 |

> 核心原则：**写操作全部走云函数鉴权**，数据库权限作为兜底。
> 「仅管理员可写」需在安全规则中自定义，或统一设为「仅创建者可读写」+ 云函数写入（云函数用 admin 权限绕过）。

**简化方案（推荐）**：所有集合权限设为「仅创建者可读写」，所有读写操作通过云函数执行（云函数拥有 admin 权限，不受集合权限限制）。这样最安全。

## 四、云函数权限说明

- 云函数默认拥有数据库的**管理员权限**，可读写所有集合
- 权限校验在云函数代码内通过 `requireAdmin` / `requireLogin` 实现
- 前端调用云函数时，云函数通过 `cloud.getWXContext().OPENID` 识别用户身份

## 五、关键配置项

### 支付开关
`cloudfunctions/pay/index.js` 顶部：
```js
const IS_MOCK_PAY = true; // 一期沙箱支付，二期改为 false
```

### 支付超时时间
`cloudfunctions/timer/index.js` 顶部：
```js
const PAY_TIMEOUT_MINUTES = 15; // 15分钟未支付自动取消
```

### 定时触发器频率
`cloudfunctions/timer/config.json`：
```json
"config": "0 */5 * * * * *"  // 每5分钟
```
