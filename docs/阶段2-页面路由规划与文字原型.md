# 阶段2：页面路由规划与文字原型

> 版本：v1.0（已确认）
> 日期：2026-10-06

## 一、整体导航架构

**底部 TabBar（4个，客户可见）**：
1. 首页 `pages/index/index`
2. 作品集 `pages/portfolio/portfolio`
3. 器材租赁 `pages/equipment-list/equipment-list`
4. 我的 `pages/profile/profile`

> 美姿灵感、套餐、预约、订单、管理员入口等均为二级页面，通过 `wx.navigateTo` 进入；档期日历嵌入管理员后台Tab内，不独立路由。

页面层级：
```
TabBar
├─ 首页
│  ├─ 套餐列表 → 套餐详情 → 预约下单
│  ├─ 器材列表 → 器材详情 → 预约下单
│  ├─ 美姿灵感
│  └─ 精选作品集 → 作品集详情 → 作品预览
├─ 作品集
│  └─ 作品集详情 → 作品预览
├─ 器材租赁
│  └─ 器材详情 → 预约下单
└─ 我的
   ├─ 我的订单 → 订单详情
   ├─ 主题设置
   └─ 管理员后台（仅管理员可见）
      └─ 内置多Tab：档期日历｜套餐管理｜作品&作品集管理｜器材管理｜美姿素材管理｜订单管理
```

**品牌文案**：光影记事｜把温柔的瞬间，交给光影（临时，后期可改）

## 三、各页面文字原型

### 1. 首页 `pages/index/index`
**目的**：品牌第一印象，快速引导到核心业务。
- 顶部：品牌名「光影记事」+ 柔和Slogan（如"把温柔的瞬间，交给光影"）
- Banner 轮播：精选作品大图（2-3张）
- 快捷入口宫格（4个）：📷 套餐预约 / 🎥 器材租赁 / 🎞️ 作品集 / 💡 美姿灵感
- 热门套餐横滑卡片：封面+名称+价格+「去看看」
- 精选作品瀑布流：缩略图，点击进入作品预览
- 底部：版权信息

### 2. 作品集 `pages/portfolio/portfolio`
**目的**：分类浏览摄影师作品集。
- 顶部分类标签：全部 / 人像 / 风光 / 活动短片
- 作品集卡片流：封面大图+标题+作品数+分类标签
- 点击卡片 → 作品集详情

### 3. 作品集详情 `pages/portfolio-detail/portfolio-detail`
- 顶部：封面+标题+描述
- 作品网格：缩略图2列布局，点击 → 作品预览
- 底部固定按钮：「预约此风格拍摄」→ 跳转预约下单（带套餐/风格参数）

### 4. 作品预览 `pages/work-detail/work-detail`
- 全屏大图/视频播放器
- 左右滑动切换同作品集内作品
- 底部：标题+描述+小贴士

### 5. 套餐列表 `pages/package-list/package-list`
- 顶部分类：全部 / 摄影 / 摄像
- 套餐卡片：封面+名称+价格+时长+「查看详情」
- 点击 → 套餐详情

### 6. 套餐详情 `pages/package-detail/package-detail`
- 封面大图
- 名称/价格/时长/分类
- 套餐描述、包含内容列表、预约须知
- 样片画廊（图片+视频）
- 底部固定按钮：「立即预约」→ 预约下单（带 package_id）

### 7. 器材租赁（器材列表）`pages/equipment-list/equipment-list`
- 顶部分类：全部 / 相机 / 镜头 / 灯光 / 配件
- 器材卡片：主图+名称+品牌型号+日租金+「详情」
- 点击 → 器材详情

### 8. 器材详情 `pages/equipment-detail/equipment-detail`
- 实拍图轮播
- 名称/品牌型号/日租金/押金
- 描述、规格参数
- 器材爱惜须知（温和走心文案，强调色提示）："本器材是个人自用设备，租金偏低，请用心呵护，人为损坏需要按维修价赔偿"
- 底部固定按钮：「单独租用」/「加入拍摄预约」→ 预约下单（带 equipment_id）

### 9. 美姿灵感 `pages/pose/pose`
**目的**：客户浏览姿势参考，无需登录。
- 顶部分类标签：站姿 / 坐姿 / 动态抓拍 / 情绪氛围感 / 双人情侣 / 短视频运镜姿势
- 卡片流大图预览：图片+姿势小贴士（柔和文案）
- 点击图片 → 全屏预览

### 10. 预约下单 `pages/booking/booking`
**目的**：核心下单页，表单+问卷+档期校验+支付。支持双向加购实现组合订单。
- **来源路径**：
  - 路径A：套餐详情进入 → 默认选中拍摄套餐，可额外加购器材（combo）
  - 路径B：器材详情进入 → 默认选中器材，可额外选择拍摄套餐（combo）
  - 路径C：只选套餐 / 只租器材
- **表单区**：
  - 拍摄日期（日期选择器，选完即触发云函数档期校验，冲突则柔和提示"这天已有安排，换个日子吧～"）
  - 拍摄地点
  - 联系人姓名 / 手机号
  - 备注
- **商品区**：根据来源展示（套餐信息 或 器材+租期天数 或 组合），提供「添加器材」入口
- **金额区**：自动计算总价
- **问卷区**（折叠，可选，「一键跳过」按钮）：
  - 期待照片氛围 / 想保留的感觉 / 介意的外貌细节 / 参考图上传 / 想对摄影师说的话
- **底部**：「提交预约并支付」
- 草稿：所有表单输入自动 `wx.setStorageSync` 存本地草稿，进入页面自动回填
- 支付：调用云函数 → 沙箱支付 → 成功后生成档期

### 11. 我的订单 `pages/my-orders/my-orders`
- 顶部状态Tab：全部 / 待支付 / 已支付 / 已完成 / 已取消
- 订单卡片：订单号、类型标签、金额、状态、日期
- 点击 → 订单详情

### 12. 订单详情 `pages/order-detail/order-detail`
- 订单状态流程条
- 商品信息（套餐/器材快照）
- 预约信息（日期、地点、联系人）
- 问卷内容（已填则展示，跳过则显示"未填写"）
- 金额明细
- 操作按钮：待支付→去支付；已支付→取消订单（释放档期）

### 13. 我的 `pages/profile/profile`
- 顶部：头像+昵称+手机号（未登录显示"点击登录"）
- 功能入口：我的订单 / 主题设置 / 联系摄影师
- 管理员入口（仅 is_admin 显示）：管理员后台
- 关于 / 版本号

### 14. 管理员后台 `pages/admin/admin`
- 单页面，内部多Tab切换，不拆独立路由
- Tab清单：档期日历｜套餐管理｜作品&作品集管理｜器材管理｜美姿素材管理｜订单管理
- **档期日历Tab**：
  - 月历视图，日期格显示档期数量标记
  - 四色区分：拍摄档期（蓝色）/ 器材租赁档期（绿色）/ 摄影师封锁（灰色斜纹）/ 器材锁定（橙色虚线）
  - 点击日期 → 弹出当日档期列表：客户姓名/地点/备注/关联订单
  - 三个操作按钮：「+ 线下档期」「+ 封锁日期」「+ 锁定器材」
    - 封锁日期弹窗：选开始/结束日期（支持单日/连续多天）、封锁范围（仅拍摄/全部）、封锁事由
    - 锁定器材弹窗：选开始/结束日期、多选器材、锁定备注
  - 已支付订单自动生成、取消自动释放
- **客户预约页（booking）**：
  - 拍摄日期 picker 设置 `min=今天`，且被 block 封锁的日期选择后提示不可约
  - 器材列表选择模式下，处于 equip_lock 区间的器材置灰并显示「已锁定」标签，不可点击
- **各管理Tab**：复用「列表+新增/编辑+删除」结构，上传图片走云存储，支持上下架

### 15. 主题设置 `pages/settings/settings`
- 4套主题卡片预览（色块展示主色/背景/强调色）
- 当前主题打勾标记
- 点击切换 → `wx.setStorageSync` 存主题key + 全局样式生效（通过 app.globalData.theme 注入各页）
