## 三、主题系统实现

- **4套主题配色**内置在 `app.js` 的 `themes` 对象中，与 `theme_config` 集合初始数据一致
- 每个页面通过 `utils/theme.js` 的 `getPageStyle(theme)` 生成内联 style，将主题色作为 CSS 变量注入页面根 view
- `app.wxss` 中所有颜色使用 `var(--primary)`、`var(--background)` 等，跟随主题动态变化
- 切换主题：`app.switchTheme(key)` 更新 globalData + 本地缓存 + 导航栏颜色；各页面 onShow 检测主题变化并刷新

## 四、核心业务实现要点

### 预约下单页（booking）
- **草稿**：表单+问卷输入自动 `wx.setStorageSync` 保存，onLoad 自动回填，提交成功后清除
- **档期校验**：选择日期后调用 `booking.checkSchedule` 云函数，冲突/封锁/锁定均柔和提示；picker `start=今天` 禁止选过去日期
- **双向加购**：从套餐详情进入可加器材；从器材详情进入可选套餐，实现 combo 组合订单
- **器材选择过滤**：跳转器材列表时携带租赁日期+天数，列表调用 `content.getLockedEquipIds` 查询锁定器材并置灰，云函数 createOrder 兜底二次校验
- **问卷**：折叠可选，含氛围/感觉/外貌细节/参考图/心里话，未填则标记 is_skipped
- **支付**：提交后调 `booking.createOrder`（云函数二次校验档期+建单+软锁档期），再调 `pay.mockPay` 沙箱支付

### 管理员后台（admin）
- 单页面 6 Tab 切换，不拆独立路由
- 档期日历：月历视图，四色标记（拍摄蓝/器材绿/封锁灰斜纹/锁定橙虚线），三个操作按钮
  - 「+ 封锁日期」弹窗：选日期区间（单日/连续多天）、封锁范围（仅拍摄/全部）、事由
  - 「+ 锁定器材」弹窗：选日期区间、多选器材、备注
  - 「+ 线下档期」原有功能不变
- 各管理 Tab：列表 + 删除，新增/编辑预留入口（待后续完善表单）
- 订单管理：查看详情、推进状态（paid→in_progress→completed）

### 订单状态流转
- `pending_payment → paid → in_progress → completed`
- `pending_payment/paid → cancelled`（释放档期）
- 非法流转云函数拒绝

## 五、Mock 降级策略

所有云函数调用失败时，页面使用本地 Mock 数据渲染，保证前端可独立浏览和调试。云函数部署后自动切换为真实数据。
